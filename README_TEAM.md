# Civic Lens — 01 Frontend Core

This package contains the files assigned to this team member for the Civic Lens project.

## Contribution workflow
1. Copy the contents into the root of the shared Civic Lens repository.
2. Create a branch using your name.
3. Commit only the files assigned to you.
4. Push the branch and open a Pull Request.

## Important
- Do **not** commit `node_modules/`.
- Do **not** commit `.env` or passwords/API keys. Create your own local `.env` from the project's environment-variable template.
- This split is based on the current Civic Lens project structure. Some files depend on files owned by other team members; that is normal in a shared repository.
